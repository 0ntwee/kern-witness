# KERN Witness

**Неизменяемый журнал событий в стиле блокчейна для автономных систем.**

[![License: AGPL-3.0](https://img.shields.io/badge/License-AGPL--3.0-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

KERN Witness — это криптографически защищенная, дополняемая система логирования событий, разработанная для автономной робототехники, IoT-устройств и систем, критичных к безопасности. Каждая запись в журнале содержит криптографический хеш предыдщей записи, создавая неизменяемую цепочку, которая обнаруживает любое вмешательство, удаление или модификацию данных.

## Почему KERN Witness?

Традиционные текстовые логи могут быть незаметно изменены злоумышленниками, повреждены при сбое системы или отредактированы инсайдерами. KERN Witness решает эту проблему с помощью блокчейн-подобной цепочки хешей:

- **Защита от подделки**: Изменение любой строки в логе ломает всю последующую цепочку хешей.
- **Защита от удаления**: Удаление любой записи создает обнаруживаемый разрыв в цепочке.
- **Работа офлайн**: Не требует интернета, облака или внешних зависимостей.
- **Легковесность**: Чистый Python, работает из коробки, без сторонних библиотек.
- **Прозрачность**: Открытый исходный код под лицензией AGPL-3.0, доступен для аудита.

## Сценарии использования

- **Автономная робототехника**: Логирование миссий, показаний сенсоров и состояний системы с криптографическим доказательством.
- **IoT-мониторинг**: Запись телеметрии устройств таким образом, чтобы её нельзя было изменить задним числом.
- **Системы повышенной надежности**: Ведение аудиторских следов для соответствия стандартам (медицинское оборудование, промышленный контроль).
- **Расследование инцидентов**: Возможность доказать, что именно произошло, когда и в каком порядке, даже после компрометации системы.

## Быстрый старт

```python
from core.witness import Witness

# Инициализация журнала
witness = Witness("my_system_log.txt")

# Запись событий
witness.log("INFO", "SYSTEM", "Система инициализирована")
witness.log("WARNING", "SENSOR", "Температура выше порога: 85°C")
witness.log("CRITICAL", "SAFETY", "Активировано аварийное отключение")

# Проверка целостности
is_valid, issues = witness.verify()
if is_valid:
    print("✓ Целостность журнала подтверждена")
else:
    print(f"✗ Обнаружены нарушения целостности: {issues}")
```

## Как это работает

Каждая запись имеет формат:
```text
[timestamp] [level] [module] message | PREV: prev_hash | SIG: current_hash
```

`current_hash` вычисляется как:
```python
hash_input = f"[timestamp] [level] [module] message{prev_hash}"
current_hash = SHA256(hash_input)[:16]
```

Это создает цепочку, где:
- Запись 1: `SIG: hash1` (PREV: "GENESIS")
- Запись 2: `SIG: hash2` (PREV: hash1)
- Запись 3: `SIG: hash3` (PREV: hash2)

Если кто-то изменит Запись 2, её хеш изменится, что сломает цепочку для Записи 3 и всех последующих.

## Безопасность

KERN Witness обеспечивает **криптографическую целостность**, а не шифрование:
- Записи хранятся в открытом виде (читаемы любым, у кого есть доступ к файлу).
- Цепочка хешей предотвращает незаметную модификацию или удаление.
- Для конфиденциальности используйте шифрование диска (например, LUKS).

**Устойчивость к атакам:**
- ✓ Обнаруживает модификацию любой записи
- ✓ Обнаруживает удаление любой записи
- ✓ Обнаруживает изменение порядка записей
- ✗ Не предотвращает чтение логов (используйте шифрование)
- ✗ Не предотвращает добавление новых записей (используйте права доступа к файлам)

## Часть экосистемы KERN SYSTEMS

KERN Witness является базовым компонентом архитектуры KERN SYSTEMS, разработанной для автономных систем, которые должны надежно работать в экстремальных условиях без подключения к облаку.
